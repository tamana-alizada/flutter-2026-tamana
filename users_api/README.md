# Users API — Practice 11

Flutter implementation of the attached Practice 11: A Real Server assignment.

## Run
```bash
flutter pub get
dart format .
flutter analyze
flutter run
```

The app loads the 10 JSONPlaceholder users, supports refresh and retry, opens a detail page, and submits a simulated new user through POST. See `NOTES.md` for field tables and the manual test checklist.

**Important:** Level 5 airplane-mode/hotspot measurements and DevTools screenshots must be collected from a real emulator or phone. JSONPlaceholder does not persist POSTed data.
